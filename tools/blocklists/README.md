# Blocklist pipeline

The generator downloads enabled HTTPS sources, normalizes them, applies the
allowlist, validates the result, and atomically replaces the static artifacts
under `apps/landing-page/public/blocklists/`. It uses only the Python standard
library.

Run locally from the monorepo root:

```sh
python3 -m unittest discover -s tools/blocklists/tests -v
python3 tools/blocklists/generate_blocklist.py --sync-seed
python3 tools/blocklists/validate_blocklist.py
python3 tools/blocklists/validate_blocklist.py --seed apps/ios/Adless/Resources/SeedBlocklist.txt
```

The normal generator refuses an empty, syntactically invalid, unexpectedly
small/large, or excessively changed list. After manual review of a legitimate
large source change, run it once with `--allow-large-change --sync-seed`.

The published SHA-256 is the hash of `blocklist.txt.gz`, not the uncompressed
text. `version` is derived from the SHA-256 of the canonical uncompressed text;
`generatedAt` is retained when the content hash does not change, so the daily
workflow does not create timestamp-only commits.

The embedded iOS seed is generated by this same command. It is a fallback only;
the app never replaces the active local list until manifest, gzip, checksum,
format, size, and domain-count validation all pass.
